# nigehbaan-site

Standalone site for nigehbaansystems.com. The home page `/` is the Nigehbaan Systems product page, in the JB Agile brand. Built with Vite, React, TypeScript and Tailwind.

Run locally:

    npm install
    npm run dev      # http://localhost:8080
    npm run build    # output in dist/

Deploys via the Vercel project `nigehbaansystems`. `vercel.json` rewrites every path to `index.html` for the single-page router.

Contact and privacy links point to https://jb-agiledev.com.
